# maybe404

Personal site for maybe404. Dark, cinematic single-page layout built with Vite, React 18, TypeScript, Tailwind CSS 3, framer-motion and lucide-react.

**Live:**
- Vercel: https://oneshort.vercel.app
- GitHub Pages: https://maybe404.github.io/oneshort/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
